# Infrastructure & Deployment

Ushbu bo'lim loyihaning infratuzilmasi, konteynerlashtirish va joylashtirish (deployment) fayllarini o'z ichiga oladi:
- **Docker & Compose**: Backend, Redis va worker konteynerlari konfiguratsiyasi.
- **CI/CD**: Avtomatlashtirilgan testlar va deployment pipeline'lari.
- **Storage & Cloud**: Audio fayllarni saqlash (S3 / MinIO) va server monitoringi.
